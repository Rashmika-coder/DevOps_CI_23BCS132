# DevOps_CI_23BCS132

## Project Description

This project is a simple Python calculator application created for DevOps Assignment 2.

The project demonstrates Git version control, GitHub collaboration, branching, merging, Pull Requests, and Jenkins Continuous Integration.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Automated testing using pytest
